# ProyectosTCPRO
# Ejercicios de Ciencia de Datos e Inteligencia Artificial - TC PRO

Este repositorio reúne ejercicios y proyectos desarrollados durante el programa TC PRO de Televisa, enfocados en el aprendizaje práctico de Ciencia de Datos, Inteligencia Artificial y desarrollo de soluciones digitales.

Durante el programa se realizaron actividades orientadas a la creación de aplicaciones, chatbots y prototipos tecnológicos, integrando herramientas como App Inventor, conceptos de IA, automatización y análisis de datos.

## Objetivo

Documentar el proceso de aprendizaje y práctica en tecnologías emergentes, aplicando conocimientos de Ciencia de Datos e Inteligencia Artificial para construir soluciones funcionales, creativas y orientadas a problemas reales.

## Temas trabajados

- Ciencia de Datos
- Inteligencia Artificial
- Creación de aplicaciones móviles con App Inventor
- Desarrollo de chatbots
- Automatización de procesos
- Análisis y visualización de datos
- Diseño de soluciones digitales
- Pensamiento lógico y resolución de problemas

## Aprendizajes principales

Este conjunto de ejercicios permitió fortalecer habilidades en análisis de información, diseño de prototipos, uso de herramientas digitales y aplicación práctica de conceptos de IA en proyectos funcionales.
